# Architecture Decision Records

One page per significant technical choice. Write them with the `/adr` skill.

Why bother: "why pgvector over Pinecone" is an interview question, and a written answer
with real tradeoffs is a director-level response where a stated preference is not. Write
for the version of yourself defending the choice eleven months from now.
